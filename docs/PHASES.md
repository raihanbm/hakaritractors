# Delivery Phases

## Phase 1 — Foundation (this package)

- Clean source structure
- Optimized assets
- Private repository
- Staging deployment
- Visual and mobile review

## Phase 2 — Product data

- PostgreSQL schema
- Product import template
- Categories, SKUs, fitment, images, and price-list design
- Admin authentication
- Initial product-management screen

## Phase 3 — Real RFQ

- Customer/company form
- Server-side validation
- RFQ number generation
- Email notifications
- Admin RFQ inbox and status history

## Phase 4 — Accounts and B2B pricing

- Secure login
- Roles and account approval
- Customer-specific pricing
- Saved machines and order lists stored on the server

## Phase 5 — Quotation, order, and payment

- Controlled quotation versions
- Proforma invoice
- Hosted payment checkout
- Verified payment webhooks
- Order status and document access

## Phase 6 — Scale and operations

- Search index
- ERP/WMS synchronization
- Image transformation pipeline
- Backups, monitoring, alerts, rate limiting, and audit review
