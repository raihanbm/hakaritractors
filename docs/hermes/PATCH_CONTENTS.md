The compact handoff zip is for an existing copy of the same Hikari project. Overlay it at repository root. It contains:

- `index.html`
- `assets/css/main.css`
- `assets/js/app.js`
- `assets/js/runtime-config.js`
- `package.json`
- `README.md`
- `robots.txt`
- `site.webmanifest`
- `scripts/audit-v4.mjs`
- `tests/*.test.mjs`
- `docs/hermes/**`

It intentionally does not duplicate the 150+ MB catalog/data/image library. Use the full zip when Hermes does not already have the original project assets.
